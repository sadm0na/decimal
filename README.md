## Глава I
### 1.1. Введение

В этом проекте вам предстоит реализовать библиотеку s21_decimal.h на языке программирования C. Цель этой библиотеки — добавить возможность работы с типом "decimal", который отсутствует в стандарте языка. Однако этот тип очень важен, например, для финансовых расчетов, где недопустимы ошибки вычислений, характерные для типов с плавающей точкой. В рамках проекта вы будете работать с задачами обработки финансовой информации, углубитесь в вопросы внутреннего представления различных типов данных и закрепите знания по структурному программированию.

## Глава II
### 2.1. Информация

Тип значения Decimal представляет десятичные числа в диапазоне от положительного 79,228,162,514,264,337,593,543,950,335 до отрицательного 79,228,162,514,264,337,593,543,950,335. Значение по умолчанию для Decimal равно 0. Тип Decimal подходит для финансовых расчетов, требующих большого количества значащих целых и дробных цифр и не имеющих ошибок округления. Тип Decimal не устраняет необходимость округления, но минимизирует ошибки округления.

Когда результат деления и умножения передается в метод Round, результат не теряет точности.

Десятичное число — это значение с плавающей точкой, состоящее из знака, числового значения, где каждая цифра в значении ranges от 0 до 9, и коэффициента масштабирования, который указывает положение плавающей десятичной точки, отделяющей целую и дробную части числового значения.

Двоичное представление значения Decimal состоит из 1-битного знака, 96-битного целого числа и коэффициента масштабирования, который используется для деления 96-битного целого числа и указания, какая его часть является десятичной дробью. Коэффициент масштабирования неявно представляет собой число 10, возведенное в степень от 0 до 28. Следовательно, двоичное представление значения Decimal имеет вид ((-2^96 до 2^96) / 10^(0 до 28)), где -(2^96-1) равно MinValue, а 2^96-1 равно MaxValue.

Коэффициент масштабирования также может сохранять любые конечные нули в десятичном числе. Конечные нули не влияют на значение десятичного числа в арифметических операциях или операциях сравнения.

#### Двоичное представление

Двоичное представление десятичного числа состоит из 1-битного знака, 96-битного целого числа и коэффициента масштабирования, который используется для деления целого числа и указания, какая его часть является десятичной дробью. Коэффициент масштабирования неявно представляет собой число 10, возведенное в степень от 0 до 28.

Десятичное число может быть реализовано как массив из четырех элементов 32-битных знаковых целых чисел (`int bits[4];`).

- `bits[0]`, `bits[1]` и `bits[2]` содержат младшие, средние и старшие 32 бита 96-битного целого числа соответственно.
- `bits[3]` содержит коэффициент масштабирования и знак и состоит из следующих частей:
  - Биты 0–15, младшее слово, не используются и должны быть нулевыми.
  - Биты 16–23 должны содержать показатель степени от 0 до 28, указывающий степень 10 для деления целого числа.
  - Биты 24–30 не используются и должны быть нулевыми.
  - Бит 31 содержит знак: 0 — положительный, 1 — отрицательный.

Обратите внимание, что битовое представление различает отрицательные и положительные нули. Эти значения могут рассматриваться как равные во всех операциях.

Пример:
```c
typedef struct {
    int bits[4];
} s21_decimal;
```

## Арифметические операторы

| Название оператора | Оператор | Функция |
|-------------------|----------|---------|
| Сложение | + | `int s21_add(s21_decimal value_1, s21_decimal value_2, s21_decimal *result)` |
| Вычитание | - | `int s21_sub(s21_decimal value_1, s21_decimal value_2, s21_decimal *result)` |
| Умножение | * | `int s21_mul(s21_decimal value_1, s21_decimal value_2, s21_decimal *result)` |
| Деление | / | `int s21_div(s21_decimal value_1, s21_decimal value_2, s21_decimal *result)` |

**Возвращаемые коды ошибок:**
- `0` — OK
- `1` — число слишком велико или равно бесконечности
- `2` — число слишком мало или равно отрицательной бесконечности  
- `3` — деление на 0

**Примечание:** При получении чисел, которые не помещаются в мантиссу во время арифметических операций, используйте банковское округление (например, 79,228,162,514,264,337,593,543,950,335 — 0.6 = 79,228,162,514,264,337,593,543,950,334)

## Конвертеры и парсеры

| Конвертер/парсер | Функция |
|------------------|---------|
| Из int | `int s21_from_int_to_decimal(int src, s21_decimal *dst)` |
| Из float | `int s21_from_float_to_decimal(float src, s21_decimal *dst)` |
| В int | `int s21_from_decimal_to_int(s21_decimal src, int *dst)` |
| В float | `int s21_from_decimal_to_float(s21_decimal src, float *dst)` |

**Возвращаемое значение — код ошибки:**
- `0` — OK
- `1` — ошибка конвертации

**Примечания по конвертации числа типа float:**
- Если числа слишком малы (0 < |x| < 1e-28), вернуть ошибку и значение, равное 0
- Если числа слишком велики (|x| > 79,228,162,514,264,337,593,543,950,335) или равны бесконечности, вернуть ошибку
- При обработке числа с типом float преобразуйте все содержащиеся в нем значащие десятичные цифры. Если таких цифр больше 7, число округляется до ближайшего, у которого не более 7 значащих десятичных цифр

**Примечание по конвертации из типа decimal в int:**
- Если в десятичном числе есть дробная часть, она должна быть отброшена (например, 0.9 преобразуется в 0)

## Глава III
### 3.1. Часть 1. Реализация функций библиотеки decimal.h

Необходимо реализовать описанные выше функции библиотеки decimal.h:

- Библиотека должна быть разработана на языке C стандарта C11 с использованием компилятора gcc
- Код библиотеки должен находиться в папке src в ветке develop
- Не используйте устаревшие и запрещенные конструкции языка и функции библиотек. Обращайте внимание на пометки legacy и obsolete в официальной документации по языку и используемым библиотекам. Используйте стандарт POSIX.1-2017
- При написании кода необходимо придерживаться Google Style для C++ 
- Оформите решение как статическую библиотеку с именем s21_decimal.a (с заголовочным файлом s21_decimal.h)
- Библиотека должна быть разработана в соответствии с принципами структурного программирования
- Используйте префикс s21_ перед каждой функцией
- Подготовьте полное покрытие кода функций библиотеки unit-тестами с использованием библиотеки Check
- Unit-тесты должны покрывать не менее 80% каждой функции (проверяется с помощью gcov)
- Предоставьте Makefile для сборки библиотеки и тестов (с целями all, clean, test, s21_decimal.a, gcov_report)
- Цель gcov_report должна генерировать отчет gcov в виде html-страницы. Для этого unit-тесты должны запускаться с флагами gcov
- При реализации decimal придерживайтесь двоичного представления с массивом целых битов, как указано в примере выше. Соблюдайте положение разрядов числа в массиве bits
- Запрещено использовать тип __int128
- Конечные нули могут быть как сохранены, так и удалены (за исключением функции s21_truncate)
- Определенный тип должен поддерживать числа от -79,228,162,514,264,337,593,543,950,335 до +79,228,162,514,264,337,593,543,950,335
